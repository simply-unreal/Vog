## Coding Style and Guidelines

All code contributed to Vog must follow these naming conventions:

* **PascalCase:** Classes, structs, and enums.
* **snake_case:** Functions and variables.

## AI Contribution Policy

AI-generated code is not permitted in any commit to this repository.

The only permitted use of AI is to assist with writing commit messages. All committed code must be written by humans.
